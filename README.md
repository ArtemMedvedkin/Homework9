# Домашнее задание к работе 9

## Условие задачи
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Ввод и валидация данных**

   -  Программа запрашивает и считывает длины трёх сторон (a, b, c) и symbol для отрисовки.
   - Проверяет корректность ввода и геометрическое свойство: существует ли такой треугольник (каждая сторона должна быть меньше суммы двух других и больше нуля). Если нет — программа завершается.

2. Математический расчёт параметров

   - Вычисляет полупериметр pp и площадь S треугольника по формуле Герона.
   - Находит высоту h, опущенную на сторону a.
   - Вычисляет проекцию x стороны c на сторону a (используя теорему косинусов) для определения сдвига вершины.
   - Переводит реальные размеры в экранные пиксели (символы) с фиксированным масштабом (masshtab = 3): рассчитывает shirina основания и vysota рисунка. Если размеры выходят за рамки консоли, программа завершается.

3. Отрисовка боковых сторон (в цикле)

Программа построчно (сверху вниз, от вершины к основанию) рассчитывает положение левой и правой границ треугольника на текущей строке kol:
   - Вычисляет отступы levo и pravo методом линейной интерполяции в зависимости от текущей высоты.
   - Печатает пробелы до левой границы, затем ставит первый символ.
   - Рассчитывает количество пробелов между сторонами, печатает их и ставит второй символ (если между ними есть расстояние).

4. **Отрисовка основания и завершение**

   - После отрисовки боковых сторон программа выводит финальную горизонтальную строку из символов длиной во всю shirina для формирования основания треугольника.
   - Функция возвращает 0 и завершает работу.

## 2. Реализация программы

```#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>
#include <math.h>
#define _USE_MATH_DEFINES
#define COL 9
#define ROW 9

int main() {

}

int zd3() {


    double a, b, c;
    double pp, S, h;
    double x;
    char symbol;




    int masshtab = 3;
    int shirina, vysota;
    int kol, levo, pravo;
    int i, probel;




    printf("Введи сторны a, b, c: ");
    if (scanf("%lf %lf %lf", &a, &b, &c) != 3) {
        printf("Ошибка ввода.\n");
        return 0;
    }

    printf("Введи символ: ");
    scanf(" %c", &symbol);

    if (a <= 0 || b <= 0 || c <= 0 || a >= b + c || b >= a + c || c >= a + b) {
        printf("Треугольник с такими сторонами не существует либо не подхожит по условию.\n");
        return 0;
    }

    pp = (a + b + c) / 2.0;
    S = sqrt(pp * (pp - a) * (pp - b) * (pp - c));

    h = 2.0 * S / a;

    x = (a * a + c * c - b * b) / (2.0 * a);

    shirina = (int)(a * masshtab + 0.5);
    vysota = (int)(h * masshtab + 0.5);

    if (shirina < 2 || vysota < 2 || shirina > 150 || vysota > 100) {
        printf("Размер не подходит для консоли.\n");
        return 0;
    }

    for (kol = 0; kol < vysota; kol++) {
        levo = (int)(masshtab * x * (1.0 - (double)kol / vysota) + 0.5);

        pravo = (int)(masshtab * (x + (a - x) * (double)kol / vysota) + 0.5);

        if (levo < 0)
            levo = 0;

        if (pravo > shirina)
            pravo = shirina;

        for (i = 0; i < levo; i++) {
            printf(" ");
        }



        printf("%c", symbol);



        probel = pravo - levo - 1;



        if (probel > 0) {
            for (i = 0; i < probel; i++) {
                printf(" ");
            }

            printf("%c", symbol);
        }

        printf("\n");
    }



    for (i = 0; i <= shirina; i++) {
        printf("%c", symbol);
    }


    printf("\n");

    return 0;
}
```
